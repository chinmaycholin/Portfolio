README: Chinmay Cholin's Portfolio Website

Project Explanation
This project is a personal portfolio website of a professional specializing in Data Structures and Algorithms (DSA) Engineering.

The website serves as a comprehensive online resume and showcase, built to:

Introduce the Developer: Provide a clear and engaging introduction, including a custom header and navigation menu.

Detail Expertise (About Me): Highlight skills (especially in Algorithmic Problem Solving, Data Structuring, and Code Optimization), professional experience, and academic background through interactive tabbed content.

Showcase Services: Outline the core DSA-focused services offered, such as Algorithm Design, Data Structuring, and Code Optimization.

Display Portfolio: Present key projects, like a Sorting Visualizer, GPS Path Optimizer (using graph algorithms like Dijkstra's/A*), and a Sudoku AI Solver (using Backtracking), clearly demonstrating proficiency in complex algorithmic concepts.

Facilitate Contact: Provide contact information, social media links, a downloadable CV, and a functional contact form that uses a Google Sheet for data collection.

Ensure Responsiveness: Implement a fully responsive design to ensure a seamless user experience across all devices, including a dedicated mobile menu.

Technologies Used
This portfolio is a static, multi-page website built entirely using foundational web technologies and leverages external libraries for enhanced features.

Frontend Languages:

HTML5: Provides the semantic structure and content of the entire site (e.g., sections for Home, About, Services, Portfolio, and Contact).

CSS3: Handles all styling, layout, visual design (dark theme with pink accents), responsiveness (using @media queries), and hover effects.

JavaScript (Vanilla JS): Implements all interactive features, including:

Tab Switching: Functionality for the "Skills," "Experience," and "Education" sections.

Mobile Menu Toggle: Logic for opening and closing the side navigation menu on smaller screens.

Form Submission: Code to handle the contact form submission and send data to an external service (Google Sheets via a script URL).

External Libraries/Services:

Font Awesome: Used to incorporate professional icons throughout the site for services, social media, and navigation elements (e.g., <i class="fa-solid fa-code"></i>).

Google Sheets API (via Script URL): Utilized for the contact form functionality, allowing form submissions to be collected in a spreadsheet without a separate backend server.
